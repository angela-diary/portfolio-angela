# Portfolio — Angela

Portfolio personnel bilingue (FR/EN), construit en HTML, CSS, Bootstrap et JavaScript. Le formulaire est volontairement prêt à être connecté à un contrôleur Laravel ; aucune adresse ou donnée de contact n’a été inventée.

## À compléter avant la mise en ligne

- Ajoutez votre fichier PDF à `assets/Angela-CV.pdf`.
- Remplacez les liens `#` et l’adresse Gmail provisoire par vos profils réels.
- Ajoutez les liens de démo et GitHub de Croq'Express.
- Lors de l’intégration Laravel, remplacez `contact.php` par un contrôleur validé qui envoie ou stocke les messages.
