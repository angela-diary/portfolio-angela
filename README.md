# Portfolio

Portfolio personnel d’Angela Ahouansou, conçu pour présenter ses projets en développement web, son parcours et ses compétences techniques.

## Présentation

Ce projet est le site portfolio personnel utilisé pour présenter une sélection de projets réalisés dans le cadre de ma formation, de hackathons et de projets personnels.

Le site met notamment en avant :

* mon parcours en développement web ;
* une sélection de projets réalisés ;
* les technologies utilisées sur ces projets ;
* un formulaire permettant de me contacter ;
* mes liens GitHub et LinkedIn.

## Projets

### Rappel+

Application web de gestion de tâches et de rendez-vous avec système de rappels.

**Technologies :** React, JavaScript, Supabase

[GitHub](https://github.com/angela-diary/rappelplus)

### Croq’Express

Site de commande en ligne pour un concept de restauration, avec menu, formules, options et panier.

**Technologies :** PHP, MySQL, Bootstrap, JavaScript

[Site](https://croqexpress.free.nf) · [GitHub](https://github.com/angela-diary/croq-express)

### ESC

Site web réalisé dans le cadre d’un hackathon pour une école spécialisée dans la savonnerie et la cosmétique.

**Technologies :** Laravel, PHP, MySQL, HTML, CSS
